# Mobile Pages Intent

- **Outcome:** Add seven new Flutter screens – Main, Auth, Settings, User, Quiz, Leaderboard, Score – with navigation between them.
- **User:** Learners / students using the mobile app to take quizzes.
- **Why now:** Provide a complete UI flow for authentication, configuration, profile management, quiz participation, ranking, and result display.
- **Success:** All new pages compile and run without crashes, navigation works as expected, the UI renders correctly, and the project's widget tests (including any new tests you add) all pass.
- **Constraint:** Use the existing Flutter SDK and dependencies; avoid introducing new third‑party packages.
- **Out of scope:** Backend API changes, advanced analytics, deep business‑logic features, or redesign of the existing web version.
